# 📘 English Writing Code Editor - yusiEditor

A lightweight experimental code editor designed to help improve English writing skills through iterative versions and progressive feature development.

## 🚀 Overview

This project consists of **four different versions** of a simple code editor, each representing an evolution in functionality and design. The primary goal is to combine coding environments with English writing practice, enabling users to improve clarity, structure, and expression while interacting with text-based interfaces.

Each version introduces incremental improvements, allowing you to observe both technical progression and usability refinement.
